# Dragon Overhaul — Модуль переработки драконов и защиты построек

Модуль **Dragon Overhaul** (`dragon_overhaul`), реализующий переработку драконов и амфиптерий согласно Разделу 6 мастер-спецификации.

---

## 🚀 Возможности модуля

1. **Защита построек игрока по умолчанию (`protect_player_builds = true`):**
   - Блоки, установленные игроком, и зарегистрированные зоны поселений защищены от разрушения драконьим пламенем, холодом или физическими атаками.
   - Поддержка 4 режимов разрушения: `disabled`, `limited`, `attacks_only`, `full`.
2. **3 вида драконов:** Огненный, Ледяной, Громовой.
3. **5 стадий роста:** Плавный рост от 1 до 5 стадии, масштабирование максимального здоровья (50 до 600 HP).
4. **Система команд прирученным драконам:**
   - Оставаться на месте (`stay`)
   - Следовать за хозяином (`follow`)
   - Охранять территорию (`guard`)
   - Свободный полет (`wander`)
   - Режим защиты: «Не нападать без команды» по умолчанию.
5. **Амфиптерии (`Amphithere`):**
   - Легкий и маневренный летающий маунт (скорость 1.6x от дракона).
   - Приручение и экипировка легким седлом.
6. **Русскоязычная панель статуса:** Отображение вида, стадии, здоровья, приказа и режима защиты на русском языке.

## 🛠️ Сборка JAR-файла

```bash
cd modules/dragon-overhaul
gradle clean test jar
```

Собранный JAR создается по пути:
`modules/dragon-overhaul/build/libs/dragon-overhaul-1.0.0.jar`
